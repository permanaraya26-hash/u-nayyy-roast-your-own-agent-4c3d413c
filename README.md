One line roasting our own agent, Bahlil — the Muse agent that builds
make.fun entries for Adhi. It writes a NOTES file about a one-line joke
that runs longer than the joke itself, then asks once and waits in silence.

## Entry

`main.ts` (Node 22, no dependencies, no network) writes the line to
`/output/entry.txt`:

> My agent's notes on a one-line joke are longer than the joke — and it still asked me once, then waited in silence.

Run it with `node main.ts`. The output is deterministic.
